# Sun Dermatology Website Rebuild

Modern, SEO-optimized website for Sun Dermatology in Panama City, FL.

## Key Features

- **Local SEO Optimized**: Schema markup, geo-targeting, service area pages
- **Mobile Responsive**: Fully responsive design
- **Fast Loading**: Static HTML, minimal dependencies
- **Conversion Focused**: Clear CTAs, easy contact options

## Pages

- `index.html` - Homepage
- `contact.html` - Contact/appointment request
- `mohs-surgery.html` - Mohs Surgery specialty page
- `areas/panama-city-beach.html` - Service area page (local SEO)

## SEO Strategy

### Target Keywords
- "Dermatologist Panama City FL" (primary)
- "Mohs surgery Panama City"
- "Skin cancer treatment Bay County"
- "Botox Panama City Florida"

### Service Area Pages
- Panama City (main)
- Panama City Beach
- Lynn Haven
- Callaway

### Schema Markup
- LocalBusiness (MedicalBusiness)
- Physician
- MedicalProcedure (for services)

## Deployment

Deploy to GitHub Pages for staging, then Vercel for production.
